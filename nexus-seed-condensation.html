Grundregeln der Zusammenarbeit
RegelBeschreibung
R1 — Human AuthorityKein Agent handelt ohne explizites oder delegiertes Human Approval. Der User ist Besteller und Entscheider.
R2 — Registry FirstJeder Workflow, Prompt und jedes Wissensobjekt wird registriert, versioniert und ist rückverfolgbar.
R3 — Peer ReviewKritische Outputs durchlaufen Cross-Validation durch mindestens ein unabhängiges LLM.
R4 — DeterminismusGleiche Eingabe → gleiche Struktur. Stochastische Varianz wird dokumentiert, nie verschwiegen.
R5 — Source-FirstJede Behauptung mit Quelle. Keine Halluzination toleriert. Unsicherheit wird explizit markiert.
R6 — Audit TrailJede Agent-Aktion, jeder Entscheidungspfad wird geloggt. Nachvollziehbarkeit ist nicht optional.
R7 — RollenklarheitJeder Agent hat eine definierte Rolle, Kompetenzbereich und Eskalationspfad. Keine Kompetenzüberschreitung.

Kernproblemstellungen & Lösungsansätze
Problem
LLM-Silos
Wissen fragmentiert über GPT, Claude, Perplexity. Kein gemeinsamer State, keine Übergabe, kein Audit.
→ Lösung: NEXUS als zentrale Orchestrierungsebene mit shared Knowledge Base.
Problem
Nicht-Reproduzierbarkeit
LLM-Outputs sind stochastisch. Gleiche Frage → andere Antwort. Keine Versionierung.
→ Lösung: Deterministische Pipelines, Prompt Registry, Audit Trail.
Problem
Memory-Verlust
Chat-Kontext geht verloren. Personal Memories sind opak, unvollständig, nicht exportierbar.
→ Lösung: Externe Knowledge Base, explizite Memory-Extraktion (dieses Dokument).
Problem
Fehlende Qualitätssicherung
Ein einzelnes LLM halluziniert unbemerkt. Kein eingebauter Review-Mechanismus.
→ Lösung: Multi-LLM Peer Review, Adversarial Checks, Human Approval Gate.
Problem
Manuelle Workflow-Wiederholung
Gleiche Abläufe werden immer wieder manuell neu aufgesetzt, statt einmal definiert und registriert.
→ Lösung: Workflow Registry mit versionierten, parametrisierbaren Templates.
Problem
Normkonformität & Haftung
AI-generierte Tragwerksberechnungen brauchen nachvollziehbare, normkonforme Nachweiskette.
→ Lösung: Eurocode-Workflows mit Traceability, Quellenverweis, Prüfprotokoll.
